# Download Ubuntu Server

Download the ARM64 ISO image of [Ubuntu Server](https://ubuntu.com/download/server/arm).

Two Ubuntu LTS versions are supported by this guide:

| Ubuntu version | PHP version | Recommendation |
|---|---|---|
| [24.04 LTS](https://cdimage.ubuntu.com/ubuntu/releases/noble/release/ubuntu-24.04.5-desktop-arm64.iso.torrent) | PHP 8.4 | For compatibility with existing Laravel Forge environments |
| [26.04 LTS](https://cdimage.ubuntu.com/ubuntu/releases/resolute/release/ubuntu-26.04.1-desktop-arm64.iso.torrent) | PHP 8.5 | For new projects using the latest Ubuntu LTS release |

Both options use the same VM architecture and networking configuration. The PHP installation instructions later in this guide cover both versions.
